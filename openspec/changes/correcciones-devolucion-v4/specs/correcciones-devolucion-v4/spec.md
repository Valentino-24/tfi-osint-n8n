# Spec Delta

## Purpose

Lista las correcciones puntuales a aplicar al informe V5 para atender la devolución V4, con énfasis en las que permiten acercarse al cierre según el Excel del tribunal.

## ADDED Requirements

### Requirement: Address blocking items
The changes SHALL address N-07 and N-08 as the main blockers for habilitation.

#### Scenario: Blockers are tracked
- **WHEN** reviewing the change
- **THEN** N-07 and N-08 have explicit tasks and acceptance criteria

### Requirement: Fix major inconsistencies
The report SHALL fix major inconsistencies (latency explanation, identifier exposure, anomaly engine efficacy statement, dictionary issues, Argentina scope, internal contradictions).

#### Scenario: Major issues are corrected
- **WHEN** reviewing the report
- **THEN** N-09 to N-14 are addressed or explicitly justified

### Requirement: Update formal elements
The report SHALL update formal elements (signatures style consistency, tools declaration, index, figures) as needed.

#### Scenario: Formal elements are consistent
- **WHEN** reviewing the report
- **THEN** formal elements are consistent with the report style
